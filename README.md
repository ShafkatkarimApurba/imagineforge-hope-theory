## Quick Start

1. Run ComfyUI locally (Pinokio recommended)
2. Clone this repo
3. `cd packages/studio && npm install && npm install konva react-konva`
4. `npm run dev`
5. Connect to `http://127.0.0.1:8188` in Settings
