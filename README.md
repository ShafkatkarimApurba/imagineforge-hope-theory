## Features (Phase 1 Complete)

- **Provider Abstraction Layer** — ComfyUI (default, local uncensored), Fal, Replicate, Custom HTTP/OpenAI-compatible. Switch instantly.
- **InpaintStudio** — Pro masked editing with Konva.js brush/erase canvas, real-time mask export, denoise/strength controls, auto gallery save.
- **ComfyUI First-Class** — WebSocket progress, image+mask upload, default T2I/Inpaint workflows optimized for 20GB RAM laptops. Fallback polling.
- **Full Studios** — Enhanced ImageStudio, VideoStudio + new InpaintStudio.
- **Hope Theory Branding** — Deep black (#0a0a0f) + electric cyan (#00f0ff) glassmorphism.

## Quick Start

1. Install ComfyUI (Pinokio recommended)
2. Clone this repo
3. `cd packages/studio && npm install konva react-konva`
4. Run the app and connect to local ComfyUI at http://127.0.0.1:8188
