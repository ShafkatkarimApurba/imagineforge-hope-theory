## ✨ Why ImagineForge?

Most AI image/video tools are either cloud-only + censored, or local but painful to use.

**ImagineForge** solves both:

- **True uncensored power** via local **ComfyUI** (primary)
- **Beautiful, modern UX** inspired by Grok Imagine
- **Full desktop experience** (Electron)
- **Extensible** — bring your own ComfyUI, Fal, Replicate, or custom endpoint

## 🚜 Quick Start

### 1. Run ComfyUI

```bash
# Easiest: Use Pinokio (pinokio.computer)
# Or manual install
```

### 2. Clone & Setup

```bash
git clone https://github.com/ShafkatkarimApurba/imagineforge-hope-theory.git
cd imagineforge-hope-theory

cd packages/studio
npm install
npm install konva react-konva

cd ../..
npm run dev
```

### 3. Connect ComfyUI
Open Settings (gear icon) → Set URL to `http://127.0.0.1:8188` → Test Connection.
